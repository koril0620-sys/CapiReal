# CapiReal · 캐피로그 실시간 상점가

같은 거리의 경쟁사 **뉴웨이브 상사**와 12개월을 버티는 실시간 경영 게임. 몇 달 뒤에는 새 경쟁사가 들어와 3~4곳이 손님을 나눈다.
가격·품질·브랜드를 바꾸면 손님 흐름이 바로 달라지고, 투자 효과는 며칠 뒤에 도착한다.

- 난도 3단계(기본·도전·극한), 조언자 4명(Raider·Guardian·Analyst·Gambler), 경영 계약, 시장 번호(시드)
- 낮·밤이 흐르는 거리 장면에서 손님이 내 가게/경쟁사로 들어가는 모습이 곧 점유율
- 월말 결산, 장부, 결과 리포트(등급·차트·조언자 브리핑)
- **경쟁사 대표 캐릭터**: 난도에 따라 준혁(기본)·준서(도전)·혜경(극한)이 뉴웨이브 상사를 이끈다. 공세·투자·가격 변경·월말 판세에 따라 말풍선으로 한마디
- **이벤트**: 결정 이벤트 8종(생산 사고·직원 이직·인플루언서·지원금·디자인 도용·배달 앱·자동화 설비·불량 민원, 결과에 확률) + 외부 충격 10종(금리·환율·원자재·소비 심리·부양책·긴축·감염병). 시장 번호(시드)로 배치가 정해지고, 기존 시장 흐름은 그대로
- **AI 조언자**: 월말 결산·결과 화면에서 버튼을 누르면 고른 조언자 말투로 AI 조언 (정답 전략은 알려주지 않고 질문으로 마무리)
- **경쟁사가 늘어나는 거리**: 4월 초와 7~8월 초에 새 경쟁사(한빛마트·루미에르·스피드몰·모노폴 중 시드로 정해짐)가 들어와 거리가 3~4곳의 싸움이 된다. 가게마다 전략(박리다매·고급화·광고·공세)과 대표가 다르다
- **파산과 교체**: 경쟁사 현금이 2달 연속 음수이거나 −1,500만 아래로 떨어지면 문을 닫고, 3일 공사 뒤 그 자리에 더 강한 가게가 들어온다. 새 가게가 들어올 때마다 경쟁 단계가 오른다(품질·브랜드·자금·공세 성향 상승)
- **시작 투자 포인트 10점**: 시작 화면에서 품질(1점 +0.1, 원가 그대로)과 브랜드(1점 +1.5)에 나눠 넣는다
- **투자 6종**: 품질 개선·마케팅 캠페인에 더해 직원 교육(품질 +0.3, 효과 빠름)·원가 절감 설비(개당 원가 −6%, 영구)·매장 리모델링(가게 매력 +6%, 최대 3번)·단골 멤버십(브랜드 +4, 5개월간 브랜드 유지). 대출·상환은 그대로 1,000만 단위
- **브금·효과음**: 경기 국면별 BGM(호황·성장·평시·위축·불황), 시작·결과 화면 BGM, 결산 BGM, 이벤트·경쟁사 공세 때 긴장 BGM, 버튼 효과음. 상단 `소리` 버튼에서 켜고 끄기·음량 조절

## 실행
```bash
npm install
npm run dev     # http://localhost:3000
```
Windows는 `start.bat` 더블클릭.

## AI 조언 설정
Vercel 프로젝트 → Settings → Environment Variables에 `OPENAI_API_KEY` 추가 후 재배포.
로컬은 `.env.local`의 `OPENAI_API_KEY`(또는 `VITE_OPENAI_API_KEY`)를 읽는다. 키가 없으면 기본 브리핑만 나온다.

## 구성
- `index.html` — 게임 전체 (화면·엔진·브금 코드)
- `api/advisor.js` — AI 조언 서버 함수 (OpenAI 키는 서버에만)
- `public/audio/` — 배경음악·효과음 (Capi-Rogue-final에서 가져옴)
- `public/img/` — 경쟁사 대표 초상화 (Capi-Rogue-final에서 가져옴)
